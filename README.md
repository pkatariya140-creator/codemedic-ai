# CodeMedic AI Framework 🩺

A privacy-first, fully localized code security auditing framework built with open-weight AI and JavaScript.

## 🚀 Challenge Requirements Satisfied

- **Open-Weight AI Model:** Uses Google's **Gemma 2 (2B)** running locally via Ollama. Zero data leakage to the cloud.
- **Agent Skill Compliance:** Strictly implements the **Agent Skill Open Standard** format defined in `skill.json`.
- **Open Source:** Published publicly under the permissive **MIT License**.

## 💻 Tech Stack
- **Backend & Server Engine:** Node.js, Express
- **AI Local Inference Framework:** Ollama
- **Frontend Layer:** Semantic HTML5, CSS3 Architecture

## 🛠️ Local Installation Setup

1. Download and run [Ollama](https://ollama.com)
2. Pull the open-weight model framework: `ollama run gemma2:2b`
3. Initialize dependency node tree packages: `npm install`
4. Deploy the runtime instance: `node app.js`
5. Open your local browser environment path: `http://localhost:3000`
